# G6: Spend

> T5's sixth slice ([generation.md](../design/generation.md), the order's G6): rate limits, budgets,
> alerts, caching, the trend. **Full tier**: new tables, routes, a notification kind, the connector's
> adapter and the usage it reports. Ken's answers of 2026-10-19 are marked **(Ken)**; the rest
> **(default)**. The pre-flight review's findings are folded in.

**Goal:** an administrator limits how often each person calls a model, sets the environment's monthly
budget, declares what a spent one stops, and is told before it is reached, through the inbox, by name;
repeated work costs less and is never served across people; and model spend reads as a trend over
twelve months (GEN-034 to GEN-036, ADM-013, ADM-014, ADM-034).

## Tasks

- **G6a**: 0132; `packages/db/src/generation-limits.ts`; `GET`/`PUT /v1/admin/generation/limits` and a person's override; both checks; the page's limits. Tests: GEN-035 a limit set, the next run refused with `resetsAt`, an override for one person, the in-stream recheck, a non-administrator refused.
- **G6b**: 0133; budget and recipients routes; `spendEnded` at the three end sites; `tellBudget`; the inbox's `budget` row. Tests: GEN-034 ADM-013 an alert at 80% before 100%, each once a month, again after a changed limit; an endpoint test's spend counted; an alert that throws leaves the run ended; ADM-014 the declaration shown; ADM-034 only named, internal administrators told.
- **G6c**: the adapters; `usage.cached` across the connector boundary; 0134 (`tokens_cached`, `cached_from` referencing `generation_run` on delete restrict, `price_cached_micros`); the result cache; the panel. Tests: GEN-036 a repeat served at no cost, another person's identical run calling the model, a changed version, a repointed base URL or boundary, a trial and an erased requester each not reused; cost with cached tokens.
- **G6d**: the usage route and page. Tests: twelve months by purpose. The walks; the final review; the close.

## Risks

- `generation_run_kept`: `cached_from` joins the set frozen while running; `tokens_cached` is written at the end, which the trigger's `old.outcome <> 'running'` already freezes after. A cached run is inserted ended, satisfying the `running`/`finished_at` check. `startRun`'s optional-column fragments are kept, as old schemas lack 0134's columns; migration tests read them through `to_jsonb`.
- The budget's sum and lock in every ending transaction: measured on a month of 10k runs, sum and lock wait, before G6b merges; an index on `(endpoint ->> 'currency', started_at)` if it needs one.

## Built

G6 in four PRs: G6a #727, G6b #728, G6c #729 and the close #730. Departures: the budget check runs in
`endRun` itself, so every place a run ends is covered; a cached run starts running and ends at once,
rather than being inserted ended; the trend shows query volume, since query runs record no cost. The
final review found no leak; it fixed spend shown to a former administrator, an alert spent on nobody,
a reused run that had proposed nothing, a typed 0 lifting every limit, a budget under a millionth
answering 500, and Run afresh outliving its part. Left, named in generation.md: one costly run can
cross a threshold and the limit together (ADM-013); trials and conversations are never result-cached
(GEN-036); ADM-033 and GEN-044 unclaimed.
