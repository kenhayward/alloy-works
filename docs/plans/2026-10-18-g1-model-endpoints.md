# G1: Model endpoints

> T5's first slice, building [generation.md](../design/generation.md)'s endpoints and run.
> **Full tier**: a migration (0120), a new connector request with a streamed answer
> ([ADR-0064](../decisions/0064-model-calls-leave-through-the-connector.md)), new routes and an
> administration page. Built inline, one final review at the slice's end. Decisions marked
> **(default)** are recommendations Ken may overturn; GN-A and GN-C are his (2026-10-18).

**Goal:** a tenant administrator configures model endpoints across providers, self-hosted ones
among them, each saying whether it sits outside the tenant's data boundary, sets each one's key
write-only, routes each purpose to one, and tests one; the test is a real model call through the
connector, streamed, recorded as a run with its tokens, cost and digest (GEN-027 to GEN-032,
IAM-076). GEN-006, GEN-033, GEN-039 and ADM-010 ask for a prompt version, a document or
generated content as well, so they are cited where those arrive (G2, G4).

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| G1-A | **An endpoint is a mutable row, audited, not a version chain** (default). A run copies the settings it used (GN-B's "as they were"), so nothing needs an endpoint's history to answer for a run. Settings: `name` (unique among those not retired), `protocol` (`anthropic`, `openai`), `baseUrl` (HTTPS, as a connection's), `model`, `contextWindow` (tokens, 1,024 to 10,000,000), `priceIn` and `priceOut` per million tokens with `currency` (ISO 4217), and `boundary`. `protocol` never changes. Retired, it routes nothing and is never deleted.                                                                                                                                                                                                                                                                                                                                                     |
| G1-B | **The key is sealed to the endpoint and its target** (default): purpose `model-credential`, context `[endpointId, protocol, origin of baseUrl]`, as `credentialContext` does for a connection; a target changed leaves the key unopenable, and the endpoint says its key needs setting again. Up to 4,096 bytes, printable ASCII (it rides a header).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| G1-C | **The connector's two new paths** (default): `POST /v1/model/seal`, and `POST /v1/model`, answered `application/x-ndjson`: each line one event (`text`, `tool_call`, `ended` with model and usage, `failed` with a failure), the last `ended` or `failed`. The child writes each event as it parses the provider's stream; the supervisor relays each line as it arrives (`SpawnChild` gains a line relay; the one-line path stays for the other kinds), kills the child past `MODEL_ANSWER_MAX_BYTES` (8 MiB), and holds at most four model calls at once, `connector_busy` beyond, so they never take every slot from queries. No failure floor: it hides a source's sign-in timing, which a model call has no use for. The deadline is the request's, 1 to 240 s, under undici's 300 s idle timeout. The server writes the head once, chunked, then each line; closing the request still kills the child. |
| G1-D | **Two adapters in the child** (default): `anthropic` posts `{base}/v1/messages` with `x-api-key` and `anthropic-version: 2023-06-01`; `openai` posts `{base}/chat/completions` with `Authorization: Bearer` and `stream_options.include_usage`. Both `stream: true`, read as server-sent events through a **streaming mode of the guarded client**: `stream(asked, policy, onData)` beside `exchange`, the same guard, connect timeout, deadline and refused redirect, but `accept-encoding: identity`, nothing buffered, each chunk handed on; a status that is not 2xx reads at most 16 KiB of the body, to classify it, never repeated (`exchange` would answer 401 as `connection_failed` and never read a 400). Text and tool calls only.                                                                                                                                                               |
| G1-E | **Failures** (default): unreachable, a refused key (401, 403), any 5xx, 429, a redirect or a stream that ends without its end event are `model_unavailable` with a reason (`unreachable`, `key_refused`, `rate_limited`, `failed`), never another endpoint (GEN-032); 400 naming length (`context_length_exceeded`, "prompt is too long") is `context_too_large`; a reply naming a model that is neither the endpoint's nor it followed by `-` and more is `model_mismatch`. Nothing of the provider's body is repeated.                                                                                                                                                                                                                                                                                                                                                                                     |
| G1-F | **The digest** (GEN-039): SHA-256, hex, over RFC 8785 canonical JSON of the provider-neutral request (`model`, `system`, `messages`, `tools`, `parameters`): what the model is given, before an adapter spells it for its provider, the key never part of it. Computed once, in the service, before the call, and stored on the run.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| G1-G | **A run row from the start** (default): `generation_run` inserted `running` before the call, ended once with `finished`, `cancelled` or a failure code, tokens and cost; a trigger refuses any other update and every delete (GEN-046). Test is purpose `test`, no document, its one message fixed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| G1-H | **The stand-in model lives beside the stand-in source** (default; GN-K said a package): `deploy/sources/http/stand-in-model.mjs`, a handler `fake-api.mjs` asks first, under `/models/anthropic` and `/models/openai`, so compose (`https://source-http/models/...`) and the connector's suite (127.0.0.1) share it and its certificate. It checks its own key (`stand-in-model-dev-key`) in either protocol's header, and `seen` drops `authorization` as it drops `x-api-key`. A reply is real server-sent events, flushed per event: the last user message `script:` and a JSON list of events streams those (a status, a cut, a pause among them); anything else answers `ready.`                                                                                                                                                                                                                        |
| G1-I | **Routes and who** (default): every route administers the tenant (`ADMINISTER`, as the tenant export's). `GET`/`POST /v1/model-endpoints`, `GET`/`PUT /v1/model-endpoints/{id}` (the whole settings), `POST …/{id}/retirement`, `PUT …/{id}/key`, `POST …/{id}/test`; `GET /v1/model-routes`, `PUT /v1/model-routes/{purpose}` with an endpoint or `null`. A route to a retired endpoint, or one whose key is not set, is refused `endpoint_unusable`.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| G1-J | **Audit** (default): `model_endpoint.made`, `.changed`, `.credential_set`, `.tested`, `.retired`, and `model_route.set`, details holding no values; a test's run id in its detail. 0120 lists `audit_event_kind` whole, as 0113 does; `kinds.ts`, the audit census, `auditWords.ts`, `wire-codes.ts` and the refusal census each gain theirs in G1b.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| G1-L | **The connector's one client gains one importer** (DAT-089, `connector-boundary.test.ts`): `apps/service/src/generation/models.ts`, the model routes, beside the connection routes; the test names both, and the client's comment says so.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| G1-M | **Rows** (default): an endpoint's name unique among those not retired (a partial index); a route set to `null` deletes its row; changing `baseUrl` is audited and leaves the key `needs_setting` until set again, as a connection's target does.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| G1-K | **The page** (default): **Models** in Administration: the endpoints, each with its protocol, model, boundary (**Outside your data boundary** where it is) and key state; Add, Edit, Set key (a password field, never shown again), Test (its reply, tokens, cost and time), Retire; and the routes, a select per purpose. Purposes but `test` are routable: `drafting`, `chat`, `summarising`, `embedding`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## Built

G1a #708, and G1b with the page and the close (0.194.0) #709: two PRs, not three, the page being
ready with the routes. Departures: an endpoint's change is `PUT` with its whole settings and its key
`PUT …/key`; the pre-flight review found the supervisor and the guarded client could not stream, so
each gained a streaming path beside the one-answer one, and the connector's boundary test names the
model routes beside the connection routes. GEN-006, GEN-033, GEN-039 and ADM-010 wait for a prompt
version, a document and generated content (G2, G4), and GEN-046 for the content a run produces: a run
is kept whole now, never changed once ended nor deleted, but retention beside its content is G3's.
The final review found a key that will not open hanging the connector's answer, a run left running
where its second transaction fails, a route set to an endpoint being retired, OpenAI's newer models
refusing `max_tokens`, a key typed for one endpoint carried to another, a person's erasure refused
by an ended run, and two citations claiming more than their tests show; all fixed. Left: a run whose
ending fails twice stays running, with no sweep; two administrators adding one name at once meet the
index's error, not `endpoint_name_taken`; a server-sent event ended by a bare carriage return is not
read.
