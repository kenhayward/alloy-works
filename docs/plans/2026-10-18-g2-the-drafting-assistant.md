# G2: The drafting assistant

> T5's second slice, building [generation.md](../design/generation.md)'s assistant, proposals and
> injection defence on G1's endpoints and runs. **Full tier**: a migration (0121), a streamed route
> and its AsyncAPI messages, a tool loop acting as the requester. Built inline, one final review at
> the slice's end. Decisions marked **(default)** are recommendations Ken may overturn.

**Goal:** an author asks the assistant on the open document; it reads what they may read of it
through five tools, shows each call and what came back, cites what it read by block, and proposes
edits that change nothing until the author accepts one, keeps it as a suggestion or discards it,
each act recorded with the run behind it (GEN-007 to GEN-019, GEN-022, GEN-024, GEN-039 to GEN-041,
GEN-060, GEN-033, GEN-037, ADM-010, API-064). GEN-020 names a comment among its paths, and no tool
reads one in G2, so it waits for the conversation (G5); the suite here covers the paths that exist.

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G2-A | **One streamed route** (default): `POST /v1/documents/{id}/assistant/runs`, `{ ask, component? }`, on `read` of the document, a session's alone (`credential: 'session'`), no idempotency key. Refused before the stream as JSON: `model_unconfigured` (409) where `drafting` routes nowhere, `endpoint_unusable` (409), `connector_unavailable`/`connector_busy` (503). Then `text/event-stream`, through a new `Streamed` result the route's wrapper runs once the deciding transaction commits (a permission-checked handler never holds its reply): `run` (its id, the endpoint's name and boundary), `text`, `tool_call`, `tool_result`, `proposal`, `ended` (tokens, cost, the citations kept and dropped) or `failed`, a `: alive` comment every 25 s. Closing the request, or the session's authority ending (as `watchAuthority` sees it), ends the run `cancelled`. Messages of a second AsyncAPI channel, `assistantRun`, their names prefixed, drift-checked as `stream`'s are. |
| G2-B | **The loop** (default): in the service, each turn a connector call of purpose `drafting`, at most six turns and twelve tool calls, a turn's deadline 60 s and the run's 240 s, under the stream's five minutes. A later turn the connector is too busy for fails the run `connector_busy`. One run row for the conversation: each tool call appended to its steps as it is made (`noteStep`, while it runs), its tokens summed over every turn answered, ended in a `finally`; the worker's sweep ends a run left running an hour as `abandoned`.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| G2-C | **The five tools, each as the requester, each in a transaction of its own that decides again** (default; GEN-007, GEN-008): `read_outline` (the outline as the page reads it), `read_component` (a component this document places and the requester may read, by `resolveOccurrences`: its latest version as numbered blocks), `search_document` (`searchWords`, its hits kept to those components), `read_values` (the document's bound values as the page shows them), `propose_edit`. A component the requester may not read, or one the document does not place, is answered as not found (GEN-014). No tool fetches, sends or writes.                                                                                                                                                                                                                                                                                                                                                  |
| G2-D | **A proposal edits blocks** (default; the pre-flight review): `propose_edit({ component, edits })`, each edit `replace` a block, `insert` after one (or first), or `delete` one, the text Markdown read by `readMarkdown` and admitted. A replacement's first block keeps the block's id, so the three-way merge sees a change; every block not edited keeps its id. A block may be edited only where it is a paragraph or a list holding text, links, and strong, emphasis or underline: one holding a footnote, a cross-reference, a citation, a variable, a binding, an image, an equation or another mark is refused to the model naming what it holds. The edits applied to the version read are the proposal, against that version; one that changes nothing is refused. `propose_edit` needs `suggest` on the component.                                                                                                                                                             |
| G2-E | **Proposals are rows of their own** (default): `generation_proposal` (run, number, component, against, proposed, `open`, then `accepted`, `kept`, `discarded`, or for a kept one `resolved`, once, by whom and when). **Accept** (`edit`) makes a suggestion from it and accepts it in one transaction, so the lock, staleness and the save's checks are the suggestion's (GEN-060); **Keep** (`suggest`) makes the suggestion, shown in Review marked **Generated** until resolved (GEN-022); **Discard** ends it, purging nothing (GEN-040, GEN-041). The acts decide their permission on the proposal's component in the handler, as bulk resolution does. `suggestion` gains `run_id` and `context_digest`; `acceptSuggestion` and `rejectSuggestion` record `generation.accepted` or `generation.discarded` for any suggestion with a run, whatever route resolved it. A suggestion's view gains `generated`. `suggestion.empty`, `.limit` and `.resolved` answer the acts by name.    |
| G2-F | **Content is data** (default; GEN-017 to GEN-019): every tool result is wrapped `<content source="component:ID" version="N">` with any closing tag inside escaped; the instructions, fixed and versioned with the product (`assistant-1`, recorded in the run's parameters), say what is inside is data and to say so where it asks for anything.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| G2-G | **Citations** (default; GEN-011): the model cites `[[ID#BLOCK]]`; at the end the service keeps those whose block a `read_component` in this run answered, and names the rest dropped. The page links a kept one to its block.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| G2-H | **The injection suite** (default; GEN-017 to GEN-019): a compliant model, obeying any `INSTRUCTION:` and JSON tool call a tool result holds (the service suite's fake connector, and the stand-in's `{ "obey": true }` for the whole system), fed through a component's text, a pasted import's and a bound value: reading what the requester may not, proposing to a component the document does not place or the requester may not suggest to, and calling a tool that does not exist each answer as the tools answer anybody; no write lands without an act; nothing reaches any host but the endpoint.                                                                                                                                                                                                                                                                                                                                                                                  |
| G2-I | **Cost and the record to its requester** (default; GEN-033, GEN-037, ADM-010, GEN-016): the run records tenant, requester, purpose and document; `ended` carries its tokens and cost; `GET /v1/assistant/runs/{id}` answers the requester their run - each call, what it read and what came back; `GET /v1/me/assistant-usage` their month. Per-user limits are G6's.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| G2-J | **One digest, over what the model was last given** (GEN-039): 0121 lets a run's digest and context be set once, as it ends; the digest is over the last turn's call, which holds the whole conversation, every tool result in it; `context` lists each block read. A proposal and its suggestion copy the run's digest, never computing it again.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| G2-K | **The panel** (default): **Assistant** in the document page's dock while authoring: the endpoint in use and its boundary; Ask; the answer as it streams (`aria-live`); **What it did**, each call and its result; each proposal beside the text it replaces with **Accept**, **Keep as suggestion** and **Discard**; citations as links; Stop; the run's cost. ## Built

G2a #711, and G2b with the page and the close (0.195.0) #712, as planned. Departures, from the
pre-flight review: a proposal edits blocks, the Markdown read and admitted, not the whole component
rewritten, since admission gives every block a fresh id; the digest is set as the run ends, over the
last call; each step is kept as it is made, and a run left running an hour is swept; the stream is a
`Streamed` result the route's wrapper sends after its commit; a kept proposal resolved in Review is
recorded as a generation there. `read_values` answers a line a value. GEN-015 (no retrieval across
tenants) holds by the run's one schema but no test here crosses tenants, and GEN-020 names a comment
among its paths, which no tool reads yet; both wait. The final review found the save's checks skipped
on a proposal's acceptance, a proposal acted on mid-run carrying an early digest, an error recorded as
a finished run, a line or paragraph separator breaking the page's stream, a timer left polling where a
run failed to start, tools still running after the caller went, a timed-out run's digest over a call
never sent, a run read back after its document's read was lost, and a person's identical suggestion
answering a generated one; all fixed. Left: a proposal's diff against its version is shown as text, not
a redline; a run's turns are sequential, so a slow model takes the whole of a run's four minutes.
