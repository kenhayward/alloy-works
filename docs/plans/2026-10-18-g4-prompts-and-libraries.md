# G4: Prompts and libraries

> T5's fourth slice, building [generation.md](../design/generation.md)'s prompts (GN-E, GN-F). **Full
> tier**: two artifact kinds, a workflow kind, a template member, migrations and new routes. Built a
> PR at a time, one final review at the slice's end. Ken's answers of 2026-10-18 are marked **(Ken)**;
> the rest are **(default)**. The pre-flight review's findings are folded in.

**Goal:** a prompt is a named, versioned, reviewed artifact declaring its context, its output and its
models; a library lists prompts and a template binds exactly one, an empty default where it names
none; an author runs a library's prompt on a part of a document, its context resolved as they may read
it, recorded and shown, its output a proposal; approving a prompt version needs a recorded trial run
(GEN-001, GEN-003 to GEN-006, GEN-045, GEN-056 to GEN-059, TPL-061, TPL-071; GEN-002 in part).

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| G4-A | **A prompt is an artifact kind in a space** (default; GN-E), `prompt`, on the version chain as a query definition is: a name, a description, its **instructions** (text with `{{parameter}}` places for the document's parameters), its **context** (G4-C), its **output** (G4-B) and its **models** (G4-D). Every list that names kinds gains it: the kind checks (0047's `artifact_space_by_kind` and `artifact_version_component_author` among them), `artifactKinds`, `spacedKinds`, substance, `LABELLED_BY`, `relatableKinds`, references, `tables.ts`, audit subject enums, `everyKind` (with `before0122`). **Not searchable** in G4, as connections and datasets are not. Audited through `artifact` events alone.                                                                |
| G4-B | **Its output is a part's text** (Ken; GEN-004 in part): `{ componentType }`, the component type it writes, or any. The model's reply is Markdown, admitted, and proposed as the whole text of the part it ran on, through G2's proposal and suggestion path; a part holding what a proposal cannot write is refused by name, as G2-D refuses. A field's value is a later slice's, so GEN-004 is named as a gap, not claimed.                                                                                                                                                                                                                                                                                                                                                               |
| G4-C | **Its context is declared, never implicit** (default; GEN-002 in part, GEN-003, GEN-056): a list of sources, each `{ outline: 'part' \| 'section' \| 'document' }` (the part it runs on, the parts of the section holding it, every part), `{ related: { type, direction } }` (components related to the part's by that relationship type), `{ field: { field, value } }` (the document's parts whose field holds that value) and `{ parameters: [names] }` (the document's values for those parameters). No tools. A query's results are a later slice's, so GEN-002 is named as a gap.                                                                                                                                                                                                   |
| G4-D | **Its models** (default; GEN-005): `{ purpose, accepts: [model ids] }`, the purpose one of the four routed ones. The run goes to the endpoint the purpose routes to; one whose model is not accepted (exactly, or followed by `-` and a release) fails `model_mismatch` before any call, and a reply naming another model fails as G1-E does.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| G4-E | **Reviewed through workflow** (default; GEN-001, GEN-045): `WORKFLOW_KINDS` gains `prompt`, following 0098 exactly; `CONDITIONS_BY_KIND` lists each kind's conditions explicitly, so documents are never offered `trial`; `decideGate` skips `fixScope`/`fixEffective` for prompts as for query definitions. G4a2's seed has no condition, so prompts are approvable from G4a2 on; G4c's seed v2 requires **`trial`**: a run of purpose `trial`, outcome `finished`, of the version being approved (GN-F), `unmetConditions` gaining the version. **A prompt workflow whose `approve`-permission transition lacks `trial` is refused** when saved, so the statement in generation.md (GEN-045) holds for every tenant.                                                                     |
| G4-F | **A library lists prompts, and floats** (Ken; TPL-061): `promptLibrary`, **tenant-wide** as a theme is (no space; administered like themes), its version a name and a list of prompts by identity. Each runs at its **latest approved version**, read through `revision_designation` (`latestRevisionsOf` in `approved` mode), not workflow state, since a saved prompt returns to draft; none where it has none. A template's definition gains `prompts`, the library's identity, optional at schema 1 as `parameters` was.                                                                                                                                                                                                                                                               |
| G4-G | **The empty default** (default; TPL-071): one library, `Prompts: none`, seeded by migration under a fixed identifier as the default theme is, `author_id` null, declared in `prompt_library_default`. A template naming none resolves to it. `resolveTemplate` reports `library` among its references (`template/resolve.ts`, `templates.ts`, the contract's unresolved enum, the web), so a template naming a missing or non-library one blocks a document as TPL-004 requires.                                                                                                                                                                                                                                                                                                           |
| G4-H | **A context resolved** (default; GEN-057 to GEN-059, GEN-043): as the person running it. Parts come from `walkOutline` with ancestors, the profile's exclusions applied as `selectOutline` does, then `resolveOccurrences`, filtered to what they read; `related` through `neighbours`, filtered to components they read, `more` failing `context_too_large`; `field` from those parts' `metadata_values`; parameters from the document's latest version, declared by `documentParameterDeclarations`. The set, by artifact, version and block, is recorded on the run's `context` before the call; nothing resolved fails `context_empty`, more than the endpoint's window `context_too_large`, never cut to fit.                                                                         |
| G4-I | **Running a prompt on a part** (Ken; GEN-006): `POST /v1/documents/{id}/prompt-runs { prompt, node }`, `read` of the document and `suggest` on the part, the prompt one of the template's library at its latest approved version, streamed as G2's runs are (`run`, `text`, `proposal`, `ended` or `failed`), single turn, the run recording the prompt version, the model, its parameters and the digest. **A trial**: `POST /v1/prompts/{id}/versions/{version}/trials { document, node }`, by anybody who may read the prompt and the document, any version, the same run with purpose `trial` (0124 widens `generation_run`'s check only; the route is the prompt's purpose), its output kept in the run's `steps` and proposed nowhere. Reads that hide `test` runs consider `trial`. |

## Built

G4 in five PRs: G4a1 #715, G4a2 #716, G4b #717, G4c #718 and the close #719. Departures: G4a split in
two, as the pre-flight review advised; libraries are the tenant's, as themes are, read across the
environment and written with `design` there; a writer may newly list only a prompt they may read,
refused alike whether hidden or missing (a security review's finding). Templates have no page in the
web app, so binding a library is the API's. The final review found no leak; it fixed a parameter's
value placed as instructions (now wrapped as data), a blank reply proposing an empty part, an unrecorded
run's end read as finished, a refused reply unseen, and a cancelled trial said as tried. Left: a field
source's match has no test; that a trial of an older version cannot approve a newer one is guarded by
the condition, not by a test; Try it lists the first 100 documents.
