# UI: Interface localisation

> T6's seventh slice. **Full tier**: a new stored preference and contract, the listing contract's
> paging, every renderer surface, a process boundary (the desktop shell). Ken's answers of 2026-10-26
> are marked **(Ken)**; the rest **(default)**. The pre-flight review's findings are folded in.

**Goal:** the interface is in each person's own language, independent of the content's (LOC-005).

- Every word comes from a catalogue in ICU message form, never assembled from fragments (LOC-027).
- Formats and plurals come from bundled, versioned CLDR (LOC-038).
- Lists are in the person's collation (LOC-003), laid out right to left where the language is (LOC-004).
- Two pseudo-locales run the interface suites from the first PR onwards, so LOC-029 and LOC-042 are verified, not asserted.
- The default theme sets Arabic (STY-075).

## Risks

- **Volume**: about 2,300 sentences in 280 files. They are moved by area, each PR's tests passing unchanged in `en-GB`, kept moved by the ratchet and checked by the pseudo walks as they grow.
- **The walks** find by English. Those running in pseudo-locales move to `say()`, a rewrite costed in each PR.
- **Bundle size**: measured at UIa against the 2.2 MB bundle and STR-073's cold open. Other locales' data is loaded lazily.
- **Paging**: a cursor's language changes the listing contract. Old cursors are refused, not misread.

## UIc2: the service's words

Each field below is added, optional and beside the English it codes, which stays for integrators.

- **The prompt's refusal**: `ended.refusal`, `nothing_written` or `edit_refused`, beside `refused`.
- **The assistant's steps**: `tool_result.said`, a `code` with its `count`, `number` or `version`,
  beside `summary`. A tool's own refusal passes its error code through. `result` is what the model was
  told, shown as a transcript: data, never worded.
- **A restore's outline reasons**: `why` beside `reason` on a document's restore refusals, one of five
  fixed reasons: `reference_refused`, `sections_added`, `sections_removed`, `sections_reordered`,
  `required_removed`.
- **Worded already from what the answer holds**: the search summary (its outcome and counts), the
  admission report (each `action` and `subject`, a test holding the catalogue to the domain's
  table) and the range preview's words (fixed, by page).
- **Left**: a refusal's `message` (each `code` worded as its folder moves, UId), and the reason an
  automatic withdrawal of a revision records, which is kept in its history as words: coding it is a
  stored shape, for when a history shows it.

## UIf: a Naskh face for STY-075

Ken's answers of 2026-10-27: a fallback chain, Word runs split by script, Noto Naskh Arabic, STY-075
amended to name its scripts, the build in UIf and the theme's version with the close in UIg. Every
consumer reads one family per typeface today, and template 25 sets Typst's `fallback: false`, so the
theme's list is the only fallback there is. The pre-flight review's fifteen findings are folded in.

| UF-B | **The shape** (stored). `typefaceSchema` gains `fallback?: typefaceId[]` (`.min(1)`), optional, so every stored theme reads as before and `THEME_SCHEMA_VERSION` stays.
