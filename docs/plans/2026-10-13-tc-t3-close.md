## TC4

STR-074, decided without Ken; each (default).

- **References it** (default): a cross-reference in a section title or a readable component's text
  whose target is the node or anything in it (a block of an occurrence, a node beneath a section),
  bound as `referenceResolver` binds it, from outside the node: one inside goes with it. One binding to
  nothing (a block not there, a component placed twice or nowhere) is not counted.
- **Computed** (default): `incomingReferences` (domain), in the page, from the outline and the texts
  it already reads (`GET /v1/documents/{id}/texts`): no index, no route, no request of its own, so the
  editor's pinned request lists are untouched. One walk of the text, each answer linear in references.
  Latest saved versions: an unsaved edit counts once saved.
- **Shown** (default): a **Referenced by** row in the Part panel, each referring place a link that
  chooses it, its count where it holds several; "Nothing else in this document refers to it." otherwise.
  Not on the tree's rows, where marks are for problems (STR-038).
- **Warned** (default): removing a referenced node says how many references it breaks and lists where,
  in the confirmation it already had; never refused.
- **Withheld** (default): a text the reader may not read is never read or counted, and a withheld
  occurrence names no component a reference could bind to (SCH-032). So a node referenced only from
  such text is removed without a warning; the publish still fails by name (STR-029).
- **Not built**: deleting a referenced block inside the component editor is not warned of before; the
  referring text shows the broken reference afterwards (STR-038). STR-074 asks for nodes, so it is
  claimed in full.
