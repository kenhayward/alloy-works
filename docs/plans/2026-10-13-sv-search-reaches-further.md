# SV: Search reaches further

> TC3 of [Closing T3](2026-10-13-tc-t3-close.md), designed in [search.md](../design/search.md), which
> claims each row. **Full tier**: stored shapes (migrations 0088, 0089), a widened contract and new
> routes; a pre-flight review and a final review. Decisions marked **(default)** are recommendations Ken
> may overturn.

**Goal:** search covers the latest version by default, and on request every earlier version or one
baseline, a result from an earlier version linking to that version (SCH-003, SCH-058); threads are
found by message and whole, as whoever may read what they are anchored to, indexed a message at a time
(SCH-071, SCH-038's T3 half).

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SV-A | **Earlier versions are kept, not re-read.** Words are made in TypeScript (`entriesOf`), so searching `artifact_version` content on request cannot be done in SQL at a bounded cost; rejected. Instead `indexVersion`, before rewriting an artifact's entries, **moves** its previous rows into `search_earlier` / `search_earlier_text` (0088): the same columns, `vector` a plain column copied, never re-tokenised; unique `(artifact_id, node, version_id)`; their own GIN, trigram and `(artifact_id, version_id)` indexes. `search_entry` and its indexes stay exactly the current set, so the default query and its cost are unchanged. Kept for components, documents, their sections and assets: what a baseline pins (default); templates, definitions and query definitions stay latest-only. A publication is already an entry per publication.                                                                                                                                                                                                                                                                                                                       |
| SV-B | **Cost and backfill.** One row per (artifact, node, version), no sharing between versions with identical words (default): a document of 200 sections cut 100 times holds 20,000 small section rows, all title and values. The load suite measures it; sharing a row across a run of versions is the next step if it bites. 0088 is listed in the runner's `REINDEXED_BY`: `reindexSearch` walks every version of those kinds in order, the latest to `search_entry`, the rest to `search_earlier` (default; a one-off cost proportional to versions, as 0031's was).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| SV-C | **The request** (`GET /v1/search`): `versions=latest` (absent) or `all`; `baseline=<id>`. Both together is 400. `all` reads `search_entry union all search_earlier`, collapsed to one result per `(artifact, node)`: its newest matching version, with `matchedVersions`, how many of its versions matched (default). Counts and facets count the collapsed results. `baseline` reads the same union restricted to the baseline's pins: its document version (the document and its sections) and each `baseline_pin` version (components, assets); a component found carries the pinned node, the first in outline order. A baseline the caller may not read, or none, is **404 `baseline_not_found`**, as every baseline route (default). Threads are in neither (SV-K).                                                                                                                                                                                                                                                                                                                                                                                                        |
| SV-D | **Permissions** (SCH-032, SCH-010): the one predicate on every branch, the readable set on the row's artifact, so a baseline-scoped search still withholds a pin the reader may not read (BL-G); neither a count, a facet nor `matchedVersions` counts anything else. Ranking stays per row, so nothing beyond SCH-032's stated residual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| SV-E | **Archived and deleted.** `archived` and `deleted` live on both tables; `archival.ts` and `deletion.ts` update both. `all` excludes both (LIF-020: archival leaves ordinary search). Within a baseline, archived content it pins is found, as its page shows it; deleted never is (DL-C refuses deleting anything pinned) (default).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| SV-F | **Paging** (SCH-022): search pages by offset over `rank desc, changed_at desc, id`, a total order; earlier rows never change but for those two flags. Search is not a listing and takes no snapshot (default): a version written between pages can still move an artifact, as today. Kept earlier rows make a snapshotted search possible later (each row would need `written_by`); not built.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SV-G | **What a result carries**: `version: { id, number, latest } \| null` (null for kinds without one here), `baseline: { id, name } \| null`, `matchedVersions` under `all`, and SV2's `thread`. `number` is `revision.version` as the Versions panel says it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SV-H | **The link** (SCH-058). No page shows an earlier version today: a component's Versions panel compares and restores, a document's restores, and only a baseline has a read-only page. So two read routes and one read-only page per kind: `GET /v1/components/{id}/versions/{version}` (content, values, number, who, when) and `GET /v1/documents/{id}/versions/{version}` (outline, values, number, who, when), `read` on the artifact, 404 for a version not its own, 410 if deleted (DL-B); addresses `#/components/{id}/versions/{version}[/blocks/{block}]` and `#/documents/{id}/versions/{version}[/nodes/{node}]`. The page renders through `renderContent` read-only, scrolls to the place, and says "An earlier version, 1.3, by Ada on 2 October. The latest is 1.7." with **Open the latest** and, for a component, **Compare with the latest**. A document's version page shows its outline and values, not its components' text (default): a document or section matches only its own words. The latest version's address opens the live page. Each Versions panel row gains **Open**. A baseline-scoped result links to `baselineLink(document, baseline, node)`. |
| SV-I | **The UI**: the Search page gains **Versions**, Latest (default) or All, and a removable **In baseline <name>** chip, set by **Search this baseline** on the baseline page; both live in the `#/search` address beside `q`. A result says "Version 1.3, earlier" or "In baseline Approved", and "Found in 4 versions".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SV-J | **Erasure** (ER-A) leaves an erased person's name in the projection: a person value is said by name when its version is indexed, and kept earlier rows would hold it for good. `erasePerson` rewrites every row, current and earlier, whose `field_values` hold the person, from its version, with the fixed word (default, SV1); a test searches the old name and finds nothing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SV-K | **Threads** (SV2, 0089): one `search_entry` per thread, `kind = 'thread'`, a new `thread_id` column (unique with `artifact_id, node`), its `artifact_id` and `space_id` **the artifact it is on** - a component, or a document for a node - so the one predicate filters it by what it is anchored to, and archival and deletion of that artifact hide it. Each message is a place, `message:<comment id>`; a span's quoted text the place `anchor`. Title: the first message's opening words; owner: who started it; changed: its latest message. A mention is indexed as its text alone, never a name (SV-J). `indexVersion`'s rewrite leaves `thread_id` rows alone. Not in `all` or a baseline: threads have no versions.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| SV-L | **Incremental** (SCH-071): 0089 makes `search_entry.vector` a plain column (`drop expression`), every writer setting it. `addComment` inserts its message's place row and appends to the entry (`body \|\| text`, `vector \|\| to_tsvector(configuration, text)`), reading neither the thread nor its other messages. `editComment` replaces its place row and rebuilds the entry's body and vector from the entry's own place rows, never the thread's tables (default). Each write is in the comment's transaction (SCH-066).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SV-M | **Resolved and orphaned threads are found** (default), the result saying resolved; orphaned is computed by the panel when opened, not in search (TH-D). The link: `#/components/{id}/threads/{thread}` and `#/documents/{id}/threads/{thread}`, the page opened at its threads panel with that thread open and the matched message focused. **Internal threads** (SCH-072, COL-038) are T4's: no internal flag exists; T4 adds it to the entry and the predicate.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SV-N | **Sweeps**: the two version routes in the access-target, cross-tenant and documentation sweeps; `SearchKind` and every kind regex gain `thread`; the leak suite (SCH-010) gains `all`, a baseline and threads, each as a reader of nothing matching. No audit kinds: search and reading a version are reads.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## Task 1: Earlier versions and baselines - SV1

- Migration 0088 (the two tables, their indexes, the grants; `REINDEXED_BY`); `search.ts` moves rows and
  `reindexSearch` walks every version; `search-words.ts` reads the union under `versions`/`baseline`;
  the contract and route; the two version routes; erasure's rewrite; the Search page, the version pages,
  Versions panels' **Open**, the baseline page's **Search this baseline**.
- Tests: **`SCH-003`** a word only in an earlier version is not found by default, found with `all` naming
  that version, and in a baseline that pins it and not one that does not; a pin the reader may not read
  neither found nor counted (**`SCH-010`**); archived out of `all`, in its baseline; the backfill of an
  existing tenant. **`SCH-058`** a result from an earlier version links to its version page, which shows
  that version's words at the place and names the latest. Erasure: the old name found nowhere. Axe in
  Light and Dark; the browser walks.

## Task 2: Threads - SV2

- Migration 0089 (`kind` widened, `thread_id`, `vector` plain); `startThread`, `addComment`,
  `editComment` index; `reindexSearch` indexes every thread; the result and link; the Threads kind.
- Tests: **`SCH-071`** found by a word in one message, naming it, and by two words in two messages;
  not found by a reader of nothing it is anchored to, on a component placed in a document they may
  read; a new message found with no re-read of the thread (its other messages' rows untouched); an edit's
  old words gone; hidden when its artifact is archived or deleted. `features.md`, `README.md`, the
  fragment.

## Final review

Hunts: a search, count or facet reaching an earlier version, baseline pin or thread its reader may not
read; the default search's plan or cost changed by 0088; an earlier row lost, duplicated or left
current by a version written under race; a thread's rows deleted by its artifact's next version; an
erased name still found.
