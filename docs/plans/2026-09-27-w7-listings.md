## W7.1: The listing shape

1. **The cursor** (`service: src/listing.ts`): `encodeCursor` and `decodeCursor` - the listing, sort,
   order, key and id; refused where it is another listing's.
2. **Keyset paging** (`db: src/paging.ts`): the predicate and the order for a sort key and the id; each
   listing's db function takes a sort and pages by it.
3. **The routes**: `sort` and `order` on all four, `cursor` and `limit` on the three that lacked them.
   **Tests:** `API-007 pages every listing by an opaque cursor over a stable order`; `SCH-022 pages
without repeating or skipping while the set changes` (rows added, changed and removed between pages,
   every order); uncited: each sort's order, a cursor from another listing refused.
4. Docs.

## W7.2: Filters, facets and the views

1. **Filters and facets** in each listing's db function, each counted without its own filter.
2. **The views**: a sort chooser and Show more on components, documents and publications, their facets
   the service's; **Templates** at `#/templates`. **Test:** `SCH-064 lists documents, components,
publications and templates, sorted and filtered`; uncited: each view.
3. Docs; features.md and the README.

## W7.3: Idempotency

1. **The record** (`0032_idempotency.sql`, `db: src/idempotency.ts`): `idempotency_record` - principal,
   key, route, path, request digest, status, body, made - read and written under the key's lock.
2. **The wrapper**: the permission-checked path honours the key in its transaction; the sample route
   through the same helper. **Tests:** `API-008 answers a retried request from its record, never doing
the work twice` (a document created once for two requests with one key, the second answered with the
   first's body); uncited: a key reused for another request refused, a refusal not recorded, a day's
   expiry, concurrent requests with one key.
3. Docs; the remainder plan's W7 row reads Built.
