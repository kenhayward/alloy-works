# VO: Vocabularies

> T7's first slice ([vocabularies.md](../design/vocabularies.md), written in VOa). **Full tier**: a
> definition kind and its migration, a field's stored shape, a publication's recorded inputs, an
> outbound fetch. Ken's answers of 2026-10-31 are marked **(Ken)**; the rest **(default)**. The
> pre-flight review's findings are folded in.

**Goal:** an administrator keeps a vocabulary, by hand or from a source; a metadata field and a
condition axis draw their permitted values from it; authors choose values by label in their
language, warned of a deprecated one and never offered a retired one; nothing a document already
holds stops validating.

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VO-A | **An environment-wide definition** (Ken), kind `vocabulary` beside `field` and `conditionAxis`, with a null space. 0176 re-issues `artifact_kind_check`, `definition_name_kind_check` and `artifact_space_by_kind` with their full current lists; `vocabulary` joins `definitionKinds`, `DefinitionOf`, `chains` and `parsers` (`metadata/migrate.ts`) and the db's and service's parsers. **Written** with `manage_definitions` through `/v1/definitions`; **read** through `/v1/vocabularies` by anyone signed in, since authors choose its values, and left out of `listDefinitions`, which needs tenant `read`. **LIB-065 supersedes LIB-001**: a vocabulary is a definition, because the fields and axes drawing on it are. LIB-001 is in no baseline. |
| VO-B | **The shape** (default): `key`, a `base` language, `names` and per value `labels` and optional `descriptions` by language (LIB-024, LIB-054), `state` `active`, `deprecated` with `replacedBy` (a value of the same vocabulary, no cycle) or `retired` (LIB-055, LIB-023), and an `id` allocated once (LIB-020, LIB-002) matching an axis key (`^[a-z][a-z0-9_]{0,63}$`). `order` is `declared` (array order) or `label` (the reader's collation, ties by id), never the store's (LIB-053). At most 5,000 values. **A version never drops an id**, retired ones included, so `refusal()` in `recordDefinitionVersion` checks against the latest version alone: no id removed, none changed in meaning, `replacedBy` acyclic.                                |
| VO-C | **A field draws on it without a new data type** (default): a `text` field's `validation` gains an optional `vocabulary: <definition id>`, so MET-002's closed set and its baseline row stand; an optional key parses every stored version 1, so no schema version step. A value held is the value's `id`, shown by its label in the reader's language, the base where it has none. Relationship-type fields may draw on one too: `relationships.ts` gets the same check.                                                                                                                                                                                                                                                                                    |
| VO-D | **Checked at save only** (MET-032, LIB-023): `checkVocabularyValues` in `metadata/`, async on a preloaded lookup as `checkUserValues` (MET-038) is, called from `unstorableValues` with the previous version's values passed from `saveIteration`. It refuses an unknown id, and a retired one the previous version did not hold. It is not part of `validate()`, so publish, promotion, restore and suggestions (which keep only `fixed` failures) are unchanged: publish lists deprecated and retired values held in its report, refusing none. The source is never reached.                                                                                                                                                                              |
| VO-E | **An axis draws on it** (LIB-022): `values` or `vocabulary`, not both; a vocabulary an axis names holds at most 200 values, checked when either is saved. One resolver, `axisValues`, gives an axis's values to `axesByKey`, `profileUnknown`, the condition dialog, the profile panel and publishing's condition evaluation. A retired value stays valid in conditions already written.                                                                                                                                                                                                                                                                                                                                                                    |
| VO-F | **Choosing** (LIB-063, LIB-054, LIB-055): the field form and the condition dialog offer active and deprecated values in the vocabulary's order, searchable past 20, each with its description; a deprecated one marked with its replacement and a Use replacement action; a retired one never offered, but shown and marked where held. Choosing a deprecated value says so at once. Labels come from `/v1/vocabularies`, so no author sees a bare id.                                                                                                                                                                                                                                                                                                      |
| VO-G | **Where used** (LIB-005): the fields and axes naming a vocabulary, and per value the components holding it, counted where unreadable (`readableAmong`), shown before a value is deprecated or retired.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| VO-H | **Pinned** (LIB-004): a publish records the vocabulary versions whose labels it printed as publication inputs of a new kind, `vocabulary`, beside terms' (`recordedTerms`, `usesIn`), with `publication_recorded_whole` extended in 0176's successor; a baseline pins them as it pins terms.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| VO-I | **SKOS in and out** (Ken; LIB-061, IMP-051): a concept scheme, values as concepts with `skos:notation` the id, `prefLabel` and `definition` by language, `owl:deprecated` with `dct:isReplacedBy`, retired as `aw:retired`, all documented. JSON-LD and Turtle in, through `terms/skos.ts`'s parser. An import creates or adds a version by key, never removes a value, and reports what it could not represent.                                                                                                                                                                                                                                                                                                                                            |
| VO-J | **From a source** (Ken: both; LIB-058): `source` is a query definition (`id`, `label`, optional `description` columns, run as the administrator through the connector) or a SKOS address, **fetched by the connector** as a built-in source behind `guard.ts` (no private or platform addresses, the address pinned, no redirect), 5 MB and 20 s, declared as leaving the boundary. Each value holds its source identifier. **Refresh is on demand**, a service-to-connector call, and records a version: new values active, labels changed, dropped values retired, with a report. A scheduled refresh waits for ADM-040. A sourced vocabulary's values are not edited by hand; their states are.                                                          |
| VO-K | **The page** (default): Administration's Vocabularies: list, make, values with labels per language, move up and down, deprecate and retire, source and refresh, export and import, where used. Its words in the catalogue; walked under axe and the pseudo-locales.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| VO-L | **Claims** (default): LIB-004, LIB-005, LIB-020, LIB-022, LIB-023, LIB-024, LIB-053 to LIB-055, LIB-058, LIB-061, LIB-063, LIB-065, MET-003, MET-032 and IMP-051 in `vocabularies.md`; LIB-004 and LIB-005 because terms and entries already meet them. LIB-030 and LIB-043 wait for the sharing slice; REU-020's note in `definitions.md` is updated.                                                                                                                                                                                                                                                                                                                                                                                                      |

## Risks

- **A field form with 5,000 values**: searchable from the first PR that offers it; a test at the cap.
- **The SKOS fetch is new egress**: the connector's guard, tested against private and redirected
  addresses.
- **A refresh run as its administrator** sees only what they may: the report names rows refused.
