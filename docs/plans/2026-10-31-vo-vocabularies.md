# VO: Vocabularies

> T7's first slice ([vocabularies.md](../design/vocabularies.md), written in VOa). **Full tier**: a
> definition kind and its migration, a field's stored shape, a new outbound fetch. Ken's answers of
> 2026-10-31 are marked **(Ken)**; the rest **(default)**. The pre-flight review's findings are
> folded in.

**Goal:** an administrator keeps a vocabulary, by hand or from a source; a metadata field and a
condition axis draw their permitted values from it; authors choose values by label in their
language, warned of a deprecated one and never offered a retired one; nothing a document already
holds stops validating.

| PR  | Holds                                                                                                                         |

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VO-A | **An environment-wide definition** (Ken), kind `vocabulary` beside `field` and `conditionAxis` (0106's pattern: `definition_name_kind_check`, `definitionKinds`), made and changed by `administer`, its values readable by anyone signed in, as a field's are. **LIB-065 supersedes LIB-001**: every library record but a vocabulary belongs to a space; a vocabulary is a definition, because the fields and axes drawing on it are. LIB-001 is in no baseline, so the gate is untouched.                                                                                                                     |
| VO-B | **The shape** (default): `key`, a `base` language, `names` and per value `labels` and optional `descriptions` by language (LIB-024, LIB-054), `state` `active`, `deprecated` with `replacedBy` (a value of the same vocabulary, no cycle) or `retired` (LIB-055, LIB-023), and an `id` allocated once (LIB-020, LIB-002). `order` is `declared` (array order) or `label` (the reader's collation, ties by id), so never the store's (LIB-053). At most 5,000 values. **A save never removes a value or reuses an id**: checked against every earlier version, so retiring is the only way out.                 |
| VO-C | **A field draws on it without a new data type** (default): a `text` field's `validation` gains `vocabulary: <definition id>`, so MET-002's closed set and its baseline row stand. A value held is the value's `id`, shown by its label in the reader's language, the base where it has none. `DEFINITION_SCHEMA_VERSION` +1 with its migration step.                                                                                                                                                                                                                                                           |
| VO-D | **Checked against what is held** (MET-032, LIB-023): at save, an `active` or `deprecated` id is accepted, a `retired` one only where the component's previous version already held it, anything else refused by name. Publish never refuses a held value; a deprecated or retired one is listed in the publish report. The source is never reached.                                                                                                                                                                                                                                                            |
| VO-E | **An axis draws on it** (LIB-022): `values` or `vocabulary`, not both; its value keys are the vocabulary's ids. A retired value stays valid in conditions already written.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| VO-F | **Choosing** (LIB-063, LIB-054, LIB-055): the field form and the condition dialog offer active and deprecated values in the vocabulary's order, as a searchable list past 20 values, each with its description; a deprecated one marked with its replacement and a Use replacement action; a retired one never offered, but shown and marked where held. Choosing a deprecated value says so at once.                                                                                                                                                                                                          |
| VO-G | **Where used** (LIB-005): the fields and axes naming a vocabulary, and per value the components holding it, counted where unreadable (`readableAmong`), shown before a value is deprecated or retired.                                                                                                                                                                                                                                                                                                                                                                                                         |
| VO-H | **Pinned** (LIB-004): a publish records the vocabulary versions whose labels it printed, and a baseline pins them as it pins terms (`baselines.ts`).                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| VO-I | **SKOS in and out** (Ken; LIB-061, IMP-051): a concept scheme, values as concepts with `skos:notation` the id, `prefLabel` and `definition` by language, `owl:deprecated` with `dct:isReplacedBy`, retired as `aw:retired`, all documented. JSON-LD and Turtle in, through `terms/skos.ts`'s parser. An import creates or adds a version by key, never removes a value, and reports what it could not represent.                                                                                                                                                                                               |
| VO-J | **From a source** (Ken: both; LIB-058): `source` is a query definition (`id`, `label`, optional `description` columns, run as the administrator through the existing connections) or a SKOS address (fetched by the worker: `https` only, no private addresses, 5 MB, 20 s; declared as leaving the boundary). Each value holds its source identifier. **Refresh is on demand** and records a version: new values active, labels changed, dropped values retired, never deleted, with a report. A scheduled refresh waits for ADM-040. A sourced vocabulary's values are not edited by hand; their states are. |
| VO-K | **The page** (default): Administration's Vocabularies: list, make, values with labels per language, move up and down, deprecate and retire, source and refresh, export and import, where used. Its words in the catalogue; walked under axe and the pseudo-locales.                                                                                                                                                                                                                                                                                                                                            |
| VO-L | **Claims** (default): LIB-004, LIB-005, LIB-020, LIB-022, LIB-023, LIB-024, LIB-053 to LIB-055, LIB-058, LIB-061, LIB-063, LIB-065, MET-003, MET-032 and IMP-051 in `vocabularies.md`. LIB-004 and LIB-005 because terms and entries already meet them. LIB-030 and LIB-043 wait for the sharing slice; REU-020's note in `definitions.md` is updated.                                                                                                                                                                                                                                                         |

## Risks

- **A field form with 5,000 values**: a searchable list from the first PR that offers it; a test at
  the cap.
- **The SKOS fetch is new egress**: the reference sources' guards, tested against private and
  redirected addresses.
- **A refresh run as its administrator** sees only what they may: the report names rows refused.
