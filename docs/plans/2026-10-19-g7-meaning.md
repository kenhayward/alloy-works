# G7: Meaning

> T5's seventh slice ([generation.md](../design/generation.md), the order's G7; [search.md](../design/search.md)'s
> Meaning; [storage-and-versioning.md](../design/storage-and-versioning.md)'s Derived data): embedding
> content, searching by meaning beside words, and costing a corpus's embedding before it runs. **Full
> tier**: new tables, a connector route and key, the worker reaching the connector, a search contract
> change. Ken's answers of 2026-10-19 are marked **(Ken)**; the rest **(default)**. The pre-flight
> review's findings are folded in.

**Goal:** every block of every searchable artifact's latest version is embedded in the background by
the tenant's embedding endpoint, inside its boundary where it chooses one; search finds by meaning as
well as words, each result labelled, a full page for a reader who sees little; and embedding a corpus,
first or again, is costed and confirmed before it runs, the old vectors serving until the new are done
(SCH-013, SCH-014, SCH-035, VER-039, GEN-038, GEN-044).

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| G7-A | **OpenAI-compatible `/embeddings` alone** (Ken; GEN-038): the embedding route takes an `openai` endpoint (`embedding_unsupported` for `anthropic`), which also covers Azure OpenAI and self-hosted servers (vLLM, Ollama, TEI), so a tenant keeps embedding inside its boundary or has no meaning search. Its boundary is shown on the route as for every purpose (GEN-031).                                                                                                                                                                                                                                                                                                                                                                                                   |
| G7-B | **The store** (VER-039, VER-040): `embedding (text_hash, model, model_version, dims, vector halfvec, made_at)`, keyed by text hash, model and model version, written once; switching models deletes projection rows, never these. `text_hash` is SHA-256 of a block's normalised words (`wordsByBlock`), a departure from the design's version hash plus block id: identical text anywhere is embedded once, the design's reason for hashing. `model_version` is the reply's `model`; a provider changing a model silently under one name is not detected, named. Erasure leaves vectors: they derive from content, which erasure keeps, never from a person's naming.                                                                                                         |
| G7-C | **Passages** (search.md's projection): `search_passage (entry_id references search_entry on delete cascade, block_id, text_hash, model, dims, vector)`, joined to its entry, so meaning reads the words' own predicate and filters from the one row they are kept on. A departure from the design's permission columns on both tables: archival, deletion, workflow and threads update entries in place, and copies would go stale, a leak; the join cannot. With iterative scan the index drives and the join filters until a page is full. `indexVersion` copies passages for every block whose hash the serving (or a confirmed pending) model holds, in its own transaction; only missing hashes wait for the job. Every passage touch is guarded for schemas before 0135. |
| G7-D | **Dimensions and the index**: 384, 768, 1024, 1536 or 3072 (`embedding_dimensions_unsupported` otherwise, found by an embed test when routed), each a partial HNSW expression index `((vector::halfvec(n)) halfvec_cosine_ops) where dims = n`. pgvector lives in `extensions`: queries write `operator(extensions.<=>)` and `::extensions.halfvec(n)` with the dimension a literal. The image is pinned to a pgvector at 0.8 or later (halfvec, iterative scan), checked by `extversion` in a test, and an `EXPLAIN` test shows the index used.                                                                                                                                                                                                                               |
| G7-E | **The worker embeds, with an embed-only key** (Ken): the connector checks keys per path, `CONNECTOR_EMBED_KEY` opening `POST /v1/embed` alone (refused elsewhere, tested); the request carries the endpoint's sealed key as `/v1/model`'s does, so the worker never holds the sealing key; a body limit sized for 96 inputs. The worker gets `CONNECTOR_URL`, the key and the private network; its client is its own small module over domain's schemas. DAT-088 holds: publishing still reads stored results only.                                                                                                                                                                                                                                                            |
| G7-F | **The job, per artifact** (GEN-033, GEN-044): `insertVersion`'s indexing enqueues `embed` for the artifact, unless one is waiting, where a serving or confirmed pending model exists; rebuilds and reindexes enqueue only for artifacts with missing hashes. The job reads the artifact's latest version, embeds its missing hashes in batches of at most 96, and writes passages for every entry holding them. Each batch is a `generation_run`, purpose `embedding`, requested by the version's author (`by` nullable), on its document where it is one, in the budget, which alerts and stops nothing (G6), and in no rate limit; `sweepAbandonedRuns` ends an abandoned one.                                                                                               |
| G7-G | **Query time** (SCH-013, SCH-031): the free words are embedded by the serving model through the service's connector client, a run of the searcher's, cached in `query_embedding (requester, text_hash, model, vector, made_at)`, the requester's alone, swept after a day and deleted on erasure, so no hit says anything about others' text. Nothing to embed (scoped terms, exclusions or filters alone), no serving model, or its endpoint retired or unanswering: words alone, the answer saying `meaning: unconfigured` or `unavailable`. Meaning searches the latest scope only.                                                                                                                                                                                         |
| G7-H | **Two strategies** (SCH-035): every predicate the words apply (`readableRow`, `shown`, `threadsKept`, the reader's filters), on the passage's entry, never a post-filter; by the readable set's estimated size, exact distance below 20,000, else HNSW with `set local hnsw.iterative_scan = relaxed_order`, `ef_search` and `max_scan_tuples` set, re-sorted. Passages collapse to their artifact, the best block its link. A test searches as a reader seeing a sliver of a large corpus and gets a full page.                                                                                                                                                                                                                                                               |
| G7-I | **One list** (SCH-014): the best 50 by words and by meaning, each over the same predicate, fused by reciprocal rank (`1/(60 + position)`), each result `found: words                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | meaning | both`; the fused list (at most 100) is what pages, `offset`and`limit` within it; the count and facets stay the words', the answer saying so. Regenerated contract and client. |
| G7-J | **Costed and confirmed** (Ken; GEN-044): routing embedding to a model the store does not serve, the first or a change, makes it pending; no job runs for it until an administrator confirms (`POST /v1/embedding/confirmation`, audited) the estimate `GET /v1/embedding` shows: distinct latest-version texts lacking it, tokens at about four characters each, at the endpoint's input price and currency, labelled approximate. The serving model answers searches until every needed text has the pending model's; then it serves at once and the old passages go. Its endpoint retired meanwhile: meaning unavailable until the switch.                                                                                                                                   |

## Risks

- SCH-067's 60 seconds is measured on the stack before it is claimed; G7 works towards it (copying at indexing, waking jobs at once) and names it.
- Migration tests run current code on old schemas: every passage, store and enqueue touch is guarded, with a test on a pre-0135 schema.

## Built

G7 in four PRs: G7a #732, G7b #733, G7c #734 and the close #735. Departures: a passage joins its entry
rather than copying permission columns; `search_text`'s words are hashed in SQL, and the queue is a
tenant table (`embedding_queued`), since a tenant's role cannot read the job queue; a confirmation's
sample learns the model's dimensions; meaning has a provisional distance cutoff of 0.75. The final
review found no leak; it fixed meaning-only results uncounted and pages cut at the fused 100, an
artifact queued for good after a refused job, a switch before every artifact had its passages, the
changed filter applied after meaning's scan, a search's embedding outside the hourly limit, a dead
model slowing every search, unchecked provider indexes, a run left open by a failed read, and a
refused sample's run lost. Left, named: SCH-067's interval unmeasured; field, condition and relation
filters applied after meaning's best 50.
