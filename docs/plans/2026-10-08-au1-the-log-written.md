# AU1: The audit log, written

> AU1 of [audit.md](../design/audit.md)'s build order. **Full tier**: a stored shape, insert-only
> grants, and a write in every act that exists, so a pre-flight review (done, folded in) and a final
> review; no per-task reviews. Three PRs; the plan rides in AU1.1 (ADR-0039). Ken may overrule.

**Goal:** every act the product performs today writes its event into the tenant's audit log, in the
act's own transaction, attributed to who did it, with the labels needed to read it after its
originals are gone; refusals and failed sign-ins are recorded in their own; acts that delete history
write first, one event per row they remove; nothing can change or delete an event. Reading and export
are AU2's.

## Task 1: The kinds, the tables, the context (`packages/domain`, `packages/db`) - AU1.1

- AU1-A to AU1-D; audit.md's Order section amended for `xact`.
- Tests: **`LIF-025`** an event cannot be updated, deleted or truncated by the tenant role, and a
  label changes only by erasure. **`LIF-030`** a detail holding a value where a name belongs is
  refused. **`LIF-032`** concurrent writers take increasing sequences, a rolled-back act leaves a gap,
  and a read bounded by `xmin` never skips a late commit. **`LIF-031`** another tenant's events are
  unreadable. Uncited: the constraint and the list agree; every kind's shape; `recordEvent` refuses
  without a context; erasure reaches every label referring to a principal.

## Verification

- Each suite alone, then `pnpm test`, `typecheck`, `lint`, `format`; `pnpm trace check` and `pins`.
- `pnpm test:e2e` and `pnpm test:browser` against the build's own compose project, every
  `ALLOY_TEST_*`, `ALLOY_E2E_*` and `ALLOY_BROWSER_*` target set. Never Ken's `alloy-works` stack.
- **The final review** breaks each citation; probes a hidden 404, a refusal in a raw-body route, a
  write path the census missed, a value smuggled into a detail, a cascade's events, the vendor's
  naming on a fresh tenant, every way a session ends, the context missing in a worker job, and erasure
  leaving every event intact.

## Risks

- **A missed emitter** is the likeliest defect; the census, over every operationId and every
  non-route writer, is the check.
- **The context**: a transaction that never sets it throws on its first event, which is the point;
  the worker and vendor paths are where it is likeliest missing, each tested.
- **Churn**: twelve migration tests pin the migration list, and refusal tests gain assertions.
