## Decisions

| GC-A | **The run, claimed** (GEN-023): `generation_run` already holds the model as its reply named it, its version within it, the prompt version and the context digest, and a suggestion names its run. A test reads them back from a prompt run's suggestion where the reply names a release of the model asked for (the `-` release `accepts` allows), so the version shown is the reply's. No schema change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| GC-B | **A publication lists the generated content it holds** (PUB-082; the pre-flight review): `publication_generated (publication_id, node, version_id, kind, suggestion_id, proposal_id, run_id)`, `kind` `suggestion` or `creation`, accepted content only, as PUB-082 asks. Written by `insertPublication` (the one path: a worker's run, a retry, a republish) beside `publication_input`, by the same history rule `generatedReport` uses (`inHistory`: a suggestion accepted into an earlier version, or the main line a divergent one left, counts). Insert-only, guarded and granted as `publication_input` is; `run_id` references `generation_run`, which is kept (GEN-046); the suggestion and proposal by id alone, so deleting nothing is blocked. 0143 backfills every publication by that rule. `generatedReport` keeps its states (open, rejected, discarded), its `inPlaced` now read from the list, so a suggestion accepted after publishing is never in it. |
| GC-C | **A prompt held to its output** (Ken; GEN-004): `output.componentType`, declared since G4 (null is any), is now enforced in `prepare`, which serves a run and **Try it** alike: a part of another type is refused `prompt_output_mismatch` before any call, its type read with the part. `GET /v1/documents/{id}/prompts` takes an optional `node` and lists only prompts that fit it, which the Assistant tab sends. Nothing else runs prompts (MCP and conversations do not). Text is the only output; a field as output stays unbuilt and is named beside the claim.                                                                                                                                                                                                                                                                                                                                                                                                    |
| GC-D | **Injection, every path** (GEN-020): the service suite's compliant fake model, obeying every instruction it finds, through a component (`read_component`), an imported document (pasted through the readers, then read as a component), a query result (`read_values`) and a prompt run's context; each instruction is data and changes nothing. A comment reaches no model: one is seeded on the very component read and on the prompt's part, and its text is in no model request recorded.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| GC-E | **A declined instruction said aloud** (Ken; GEN-021): a `declined` tool `{ where, instruction }` given to conversation runs (a prompt run has no tools, GEN-003); the instructions ask the model to call it when content asks something of it. ## Risks

- **A notice is the model's word**: only a model that calls `declined` reports one; the suite's stand-in does, a real one may not.
- **GC-B's backfill** runs current code's rule over old rows: written in SQL in 0143 from `to_jsonb`, so its migration test holds on old schemas.

## Built

GC in two PRs: GCa #751 and the close #752. Departures: conversations take their own instructions
(`conversation-1`), asking the model to call `declined`, while the document assistant keeps GEN-007's
