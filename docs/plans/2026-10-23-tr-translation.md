# TR: Translation

> T6's fifth slice. **Full tier**: a stored shape on `artifact_line` and two new tables, the editing
> lock's key, a publication request's new member, the outline's new members, a tenant policy. Ken's
> answers of 2026-10-22 and 2026-10-23 are marked **(Ken)**; the rest **(default)**. XLIFF, jobs and
> machine translation are XL's; interface localisation, HTML and the index are UI's (Ken). The
> pre-flight review's findings are folded in.

**Goal:** a component is translated as a line of its own per language; each variant knows the source
version it translates and goes out of date the moment the source changes; a document publishes in a
language, falling back to the source where a variant is missing, marked; status shows wherever a
component is used and across a space.

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TR-A | **A variant is a language line** (Ken; LOC-007, LOC-012): `artifact_line.language`, a BCP 47 tag, null for a divergent line; its `name` the tag, so a divergent line already so named refuses it (`line.name_taken`); a partial unique index on `(artifact_id, language)`. Its own workflow and scope (LIF-044), so approval stays a workflow state (LOC-030). Never brought back or compared: return and comparison refuse `line_is_translation`. Not closed or deleted in TR (named). Readers on schemas before 0159 read `to_jsonb(l)->>'language'`.                                                                             |
| TR-B | **Begun from a designated revision** (default): `POST /v1/components/{id}/translations`, by whoever may edit, audited `line.diverged` with the language; from the source's latest designated revision, as R16 begins a line, so `diverged_from` stays required and labels stay `fr 2.1`; a component never designated refuses `translation.needs_revision`. Beginning cuts no version: a line with no version of its own is `untranslated` and resolves as missing. A language equal to the source's is refused.                                                                                                                    |
| TR-C | **What a variant translates** (default; LOC-013): `translation_state (line_id, version_id, translates, by, at)`, insert-only, the newest row a line's. A save on a language line names the main-line version the translator was shown; the service checks it is this component's main line and refuses a stale one `version.precondition`. **Mark current**, by whoever may edit, records the line's head against a named source version without cutting one, audited `translation.marked_current`.                                                                                                                                 |
| TR-D | **A source change declared** (default; LOC-015, LOC-031): a main-line save carries `retranslate`, default true; `source_change (version_id, retranslate, by, at)`, insert-only, the newest row a version's, revisable by whoever may edit, audited `translation.declared`. Who may translate is who may edit (LOC-031's words). A version with no row, a restore, a return, an import, a promotion, counts as `retranslate`.                                                                                                                                                                                                        |
| TR-E | **Status, computed** (Ken: per component, blocks shown; LOC-014, LOC-030): `untranslated`, `translated`, `outOfDate` with `retranslate` true if any main-line version after `translates` is declared so. Never stored, so it goes out of date at the source's save, mechanically. `machineDrafted` and `inTranslation` are XL's; LOC-030 is claimed there.                                                                                                                                                                                                                                                                          |
| TR-F | **The previous translation is the start** (default; LOC-040): an out-of-date variant opens on its own head beside the source's changed blocks, `GET /v1/components/{id}/lines/{line}/source-changes` (read) comparing `translates` with the main line's head by block id; the variant keeps the source's block ids.                                                                                                                                                                                                                                                                                                                 |
| TR-G | **Approved never reads a language line** (review): `latestRevisionsOf` and `effectiveRevision` leave language lines out unless one is named, so a variant's designation never becomes another language's, or the source's, approved revision; tested. A divergent line's revision still serves, as R16 meant (LIF-046). Language lines are left out of `openLinesOf`, so they never read as **Diverged**.                                                                                                                                                                                                                           |
| TR-H | **One lock per line** (review): the editing lock is keyed `(artifact_id, line_id)`, so translators and the author edit at once; a return takes both its line's and the main line's.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| TR-I | **Publishing in a language** (default; LOC-010): `RequestPublicationBody.language`, default the document's, held on the publication for the worker and preview; each reference resolves on that language's line: latest its newest version, approved its latest approved revision, pinned the newest variant version translating the pinned version or an earlier one. A component whose root language is the one asked for is its own variant. A pin to a language line's version is refused. A baseline publishes in its own language only; another is refused (named). Fallback and staleness are recorded per input at request. |
| TR-J | **Fallback, marked** (Ken: fall back by default; LOC-037, LOC-017): `translation_policy` (`fallback: source \| refuse`, `outOfDate: publish \| refuse`, defaults `source` and `publish`), a tenant setting beside import's, audited `settings.changed`; the outline's optional `fallback` overrides it per document. Refusal counts only `retranslate` changes. A fallen-back component carries its own language tag (PDF `Lang`, Word `w:lang`) and the theme's **Untranslated** note; the report lists it.                                                                                                                        |
| TR-K | **The layout and terms** (review): a publish in a language needs a layout that speaks it (PUB-095), else refused; terms resolve in it (TM-F). A reference's overrides are not applied to a variant and are reported; per-language overrides are named.                                                                                                                                                                                                                                                                                                                                                                              |
| TR-L | **Titles by language** (Ken; LOC-Q04): optional `titles` on the outline's root (strings) and on a section (`sectionTitleSchema` values), a map from language to title, in the canonical form where present, set by a `retitle` carrying a language; a key equal to the outline's language refused; templates carry them. The contents, bookmarks, running heads and cross-references show the language's title; a missing one prints the source's and is reported. The structure is never translated.                                                                                                                               |
| TR-M | **Status where used** (default; LOC-016): a document's reference row says each language's status; the component page's **Translations** lists them; `GET /v1/spaces/{space}/translations` reports every readable component by language, filtered before it counts, paged and capped (API-058). Search results and listings are named.                                                                                                                                                                                                                                                                                               |
| TR-N | **Languages** (default): any BCP 47 tag `publishedLanguage` can carry; the declared list is LOC-038's, in UI.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## Risks

- **`latestRevisionsOf` has some twenty callers**; leaving language lines out is tested at each
  kind of caller; divergent lines' revisions serve as before.
- **The lock's key** changes editing's one guarantee; its tests are rerun per line.
- **LOC-036** wants policies versioned; the settings row is updated in place with the audit holding
  before and after. Claimed in XL when every policy it names exists, or the gap named.
- **Census**: access-routes, audit-census and cross-tenant rows for every new route; 0112's insert-only
  grants for both tables; the audit kind check and `audit/kinds.ts` together.
