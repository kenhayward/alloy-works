# IM: Import

> T6's fourth slice ([import.md](../design/import.md), ADR-0069). **Full tier**: an untrusted file
> parsed in the worker, new tables holding a proposal apart, a transaction making a document and its
> components, identities from outside the tenant. Ken's answers of 2026-10-22 are marked **(Ken)**;
> the rest **(default)**. The pre-flight review's findings are folded in.

**Goal:** a person imports a Word, Markdown or HTML document as a reviewed proposal of sections and
components, its structure kept, its tracked changes and comments as suggestions and threads, and
accepts or abandons it; importing it again proposes its changes as suggestions.

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IM-A | **A proposal held apart** (Ken; ADR-0069; IMP-001 to IMP-003, IMP-048): 0155's `import` (space, importer, file by hash, kind `first` or `again`, state reading, proposed, accepted, abandoned or failed) and `import_part` (section or component, order, title, blocks, the source fragment it came from, its reason, its flags), with the proposal as read kept beside the edited one. Seen only by its importer and the space's administrators; importing needs the space's create-document permission. Nothing runs unattended: a person starts each import and accepts it.                                                                                                                                                                                                                                            |
| IM-B | **The file** (default): an import upload kind beside assets', `.docx`, `.md`, `.html`, 25 MB, by hash in the tenant's store; deleted with its import unless another import holds the same hash.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| IM-C | **Read in the worker** (default; ADR-0069; IMP-047): job `import`, a memory limit and a timeout. A zip's entries are checked by name (no `..`, absolute path, backslash or duplicate), counted (1,000) and inflated against caps as they stream (200 MB in all, 20 MB a part), never written to disk, only the parts expected read. XML by `saxes` with DTDs refused (a billion-laughs and an external-entity fixture tested); nodes and depth per part capped. Macros (`.docm`, vbaProject), OLE and ActiveX parts, external relationships and links whose scheme is not allowlisted are never stored or fetched, and are reported. Images inside go through asset ingest; a format it refuses is reported. Each part is admitted as a paste is (CNT-130, IMP-017). The T1 spike importer and its case test are retired. |
| IM-D | **Breakout** (Ken; IMP-004, IMP-030): Heading 1 a section, Heading 2 a component, deeper headings inside it, content before the first heading an introduction; the levels the importer's to change, proposing again. Each part's reason names its heading's style and text.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| IM-E | **Review** (Ken; IMP-028, IMP-029, IMP-041): one part at a time beside its source fragment and reason; searched by title and text, filtered by flag; a split moved, parts merged or renamed, each edit validated as made and refused if what it produces would fail validation. IMP-031 compares the accepted outline with the proposal as read.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| IM-F | **Accept and failure** (default; IMP-008, IMP-042): one transaction makes the document (the space's default template, or the one chosen), its sections, each component at 0.1 by the importer, then suggestions and threads; provenance (IMP-035) on each. Accepting is refused while a reference is unresolved (IM-H). A failed or abandoned import deletes its parts and file and says what happened; a proposed one untouched for 30 days is swept, its importer told seven days before.                                                                                                                                                                                                                                                                                                                               |
| IM-G | **Tracked changes and comments** (IMP-005): a component's 0.1 is its text with every change rejected; each Word author's changes become one suggestion against 0.1; a change crossing a split is kept in the part it starts in and flagged; overlapping authors' suggestions may not merge cleanly, as any two may not. A comment becomes a thread anchored to its span, clamped to the part it starts in and flagged where it crossed; replies become its comments. `attributed_to` is a sibling table (suggestions and threads are insert-only).                                                                                                                                                                                                                                                                        |
| IM-H | **References outside the import** (IMP-033, IMP-034): each listed before acceptance with the text it had in the source; each retargeted by the person, or converted to plain text with that named in the report, or the import refused; never resolved silently.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| IM-I | **Identities** (Ken; IMP-009 to IMP-011, IMP-032): shown as carried in review; at acceptance the tenant's `import_policy` (a singleton as `editing_policy` is, set in Administration): map (the default) maps an exact email match to that member, flagging a name match for the importer to confirm; keep; discard. Mapping attributes, it never authors (the IMc security review): everything an import makes is made by its importer, the matched member recorded beside it; a confirmation must name the member the identity matches. Which applied is recorded on the import and on each suggestion and thread.                                                                                                                                                                                                      |
| IM-J | **The file's metadata** (default): its own properties and personal metadata (author, last saved by, device and location fields) discarded by default, kept only as the policy says. IMP-012 stays unclaimed: an image's own metadata is AST-007's (T7).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IM-K | **Re-import** (Ken; IMP-036, IMP-037): a file whose hash or name in the space an earlier import matches is said so first, with the earlier import named; its proposal (kind `again`) matches parts to the components that import made by provenance; a changed part is a whole-component suggestion against that component's current version, a new part a new component, a part gone flagged; reviewed as any proposal. Edits made in the space are never overwritten.                                                                                                                                                                                                                                                                                                                                                   |
| IM-L | **The round trip stated** (IMP-026, IMP-025): on the import's review header and a Help page, what Word structure arrives and what does not, never saying lossless; tested.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| IM-M | **IMP-016 to T7, PUB-028 to T8** (Ken): with change histories; PUB-028's import half is IMP-005's.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## Risks

- **A .docx is hostile input**: IM-C's caps, enforced while streaming, are the line.
- **Word's structure is loose**: what the reader cannot place is reported, never silently dropped (IMP-007).
