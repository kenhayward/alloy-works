# R2: Impact, and placing another document's section

> T4's second slice, extending [relationships.md](../design/relationships.md) and
> [structure.md](../design/structure.md). **Full tier**: migration 0102, a stored index, new routes and
> an outline operation. Built inline, one final review at the slice's end (Ken, 2026-10-14). Decisions
> marked **(default)** are recommendations Ken may overturn.

**Goal:** references are indexed as each version is cut; what a change to any artifact reaches is
answerable to a depth, bounded and permission-filtered, as is what an artifact uses; and an author
places another document's section as references under a new section of their own, told first how much
it pulls in (SCH-023, SCH-024, REL-017 to REL-020, REL-030, REU-046, REU-054).

## Decisions

| ID   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R2-A | **The reference index** (0102): `reference (from_id, from_version, node, to_id, to_kind, mode, to_version)`, one row per reference in each artifact's **latest** version, replaced in `insertVersion`'s transaction. A document's: each component it places (its mode and pin) and its template version (pinned). A component's: each figure's and inline image's asset version (pinned), and each binding's query definition (pinned where the binding names a version, else `latest`). A query definition's: its connection (`latest`). Backfilled from latest versions in the migration; a derived index, so `on delete cascade`.                                                                                                                                                                                                                            |
| R2-B | **Uses read the index** (R1-A's promise): the same answer, no `jsonb_path` scan.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| R2-C | **Impact** (REL-022's references half): `GET /v1/artifacts/{id}/impact?depth=` walks edges into the artifact a depth at a time, each artifact once at the least depth it is reached (REL-018). Depth is required, 1 to 10 (REL-017). Each artifact is tested against the caller's readable set as it is reached: one that fails is neither returned nor expanded, and the answer says a path was cut (REL-019, REL-020). It stops at the nearest 1,000 and says whether there were more (REL-030). A deleted artifact is neither returned nor expanded. Each result names its kind, title, depth and the artifact it was reached through. Every result is `hard`, a chain of references.                                                                                                                                                                        |
| R2-D | **Iterated in TypeScript, a query per depth** (default), not one recursive statement: at ten hops at most, ten queries, each over the index's `to_id` key, keep the visited set and the cap exact, and the permission step is the one predicate listings use. The design's recursive SQL stays the route to a million-component budget (REL-031), measured when the graph view arrives.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| R2-E | **What an artifact uses** (SCH-024): `GET /v1/artifacts/{id}/references`, one hop forwards, readable named and the rest flagged.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| R2-F | **Placing a section** (REU-054): a preview, `GET /v1/documents/{id}/placement?from=&section=`, reports how much it pulls in: the components, the occurrences, and their blocks and characters at the versions it would take (REU-046). The act, the outline's `place` operation, against the source version the preview read: a new section under the author's chosen parent, titled by the author, taking its fields from the author's own template as any inserted section does (STR-060) and copying no values; one reference per occurrence in the source section's subtree, in order, each in the mode the author chose among REU-050's three (pinned to each component's version now). Nothing links the new section to the found one (STR-004). Refused where the source section places a component the author may not read, or moved since the preview. |
| R2-G | **Left for later.** The background impact report and the job contract (REL-032, REL-050, API-040 to API-043) are R3's. Declared relationships, and with them informational impact and REL-022's and REL-023's claims, are the graph slice's. REU-052 still waits on styles, terms and vocabularies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## Task 1: The index and impact - R2a

- 0102 and its backfill; `domain`: `referencesIn(substance)`; `db`: write in `insertVersion`, guarded
  for schemas before 0102; `impact`, `referencesFrom`; uses on the index. Contract, routes,
  documentation, census lists.
- Tests: rows replaced as versions are cut, of each kind, and backfilled; impact through two hops, its
  depth refusals, a cycle (rows written directly), a cut path, the cap; what a component uses.

## Task 2: Placing a section - R2b

- Domain `place`; db preview and act; the route; the outline pane's **Place from a document**.
- Tests: the report; the section and its references in order and mode; refusals; the page. The final
  review hunts a component placed that the author may not read, and a value copied. The close: 0.173.0.
