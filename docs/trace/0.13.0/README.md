## What is in this pack

- `README.md` - this file: the version, the commit, the baseline and whether it passed.
- `matrix.md` - one row per requirement this baseline claims: its statement, tranche, the design that answers it, the test or declaration that verifies it, and the gate's verdict.
- `gaps.md` - every problem in the corpus, every requirement this baseline explicitly excludes and why, and how many in-force requirements this release simply does not claim, by tranche.
- `results.md` - the test evidence behind the matrix, one row per citation.

This pack is evidence about a **declared scope**, not about the whole product: see `gaps.md` for what it does not cover, and `docs/specification/baselines/README.md` for what a baseline is.
