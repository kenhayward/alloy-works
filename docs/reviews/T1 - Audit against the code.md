# T1 - Audit against the code

**Date:** 2026-09-25, at 0.69.0 (after PR #228, themes 2).
**Asked for by:** Ken, once themes for the PDF had landed: check every T1 requirement that is not
yet `Covered` against the code, recommend what leaves T1, and plan the rest.
**Answered in:** the change history of each requirements document it changed (a **From the T1 audit
against the code** subsection), and [the T1 remainder plan](../plans/2026-09-25-t1-remainder.md).

Like every other review in this folder, this is kept as it was written. The file paths and line
numbers below point at the tree at 0.69.0 and will drift; the verdicts are the record.

## What was checked, and how

`pnpm trace tranche T1` at 0.69.0 counted 381 requirements in T1: 169 not `Covered` (84
`Specified`, 85 `Designed`), across thirteen areas. They were split into seven groups by subject and
each group was read against the code by one auditor, under one brief:

- `pnpm trace show` for the statement, its design and any citing test; then the code and its tests.
- One verdict each: **CITE** (an existing test demonstrates the whole statement - only the whole),
  **TEST** (built, but no test shows the whole), **PARTIAL**, **NOT BUILT**, or
  **CONSTRAINT-LIKE** (a practice or a budget rather than a feature).
- A tranche recommendation against the scope's phasing (Project_Scope.md section 12), moving a
  requirement only with a concrete reason: something it depends on that T1 does not have.
- Read only: no test was run, nothing was changed.

Every proposed citation was then checked against its statement by hand before it was applied.

## Findings that are not about tranches

These are true at 0.69.0, found in passing, and each has a home in the plan.

**Defects.**

- **PUB-003:** `assemble` projects contributions from each occurrence's content before `conditions`
  runs (packages/domain/src/publishing/assemble.ts:217-220), the order publishing.md's own finding 3
  names as wrong. It does no harm while `conditions` is the identity, but it must be fixed before
  REU.
- **VER-003:** an iteration's `expires_at` is set when it is written. So an iteration older than
  the window when a version is cut could be swept at once, with no window after the cut. Nothing
  sweeps yet, so no data is at risk.
- **CNT-069:** the editor's history runs at ProseMirror's default depth of 100 events. A long session
  cannot undo back to where it opened.
- **CNT-075:** the read-only text and the editing surface disagree on ligatures and on runs of spaces
  (the `.ProseMirror` rules in packages/editor/style.css are not applied to rendered text).
- **CNT-079:** a definition list's definition is a `p` inside a `div`, not a `dd`, so assistive
  technology is not told it is a definition.
- **CNT-074:** the lock notice never shows when the lock is expected to release, although the API
  returns it.

**Design text that no longer matches the code.**

- publishing.md:120 names a `citation_unresolved` failure; a citation fails as
  `inline_not_publishable`.
- content-model.md said an OOXML reader answers Word paste; paste reads Word's HTML clipboard. It
  was corrected with the CNT-060 split.
- structure.md said CNT-125 was not demonstrated for an equation. It was corrected with the
  citation.
- publishing.md's "Where the code lives" puts veraPDF in the worker's job; it runs only in tests.
- docs/features.md says in one place that the document's text is shown with components edited in
  place, and in two others that there is no document view. CLAUDE.md says the latter.

**A citation that claims too much.** CNT-124's only citation
(packages/domain/src/content/model/document.test.ts:74) shows its first sentence. The second, "a
newly created component must hold exactly one empty paragraph", is shown by
packages/db/src/creation.test.ts:81, which cites nothing.

**The per-format rows are best left whole.** Eight "every output" requirements (PUB-012, PUB-034,
PUB-092, CNT-045, CNT-084, CNT-128, TAB-039, TAB-049) have their PDF half demonstrated. Splitting
them by format would allow PDF citations now. But both halves are T1, and they close together when
Word lands.
