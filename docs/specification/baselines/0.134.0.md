# 0.134.0

> **Declared:** 2026-10-05. What this release is answerable for: every requirement 0.133.0 declared,
> carried forward, and the one B2 verifies - which identity a query runs as, shown to every author
> using it.

## Included

| ID          | Why it is in force                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IAM-004** | A generic harness in `apps/service/src/cross-tenant.test.ts` iterates every authenticated route in the API contract, signs in to one tenant, and asserts a refusal when that session is presented to another tenant's hostname - a route added later is covered without the harness changing                                                                                                                                                                                              |
| **IAM-043** | Sign-in refuses to start a route a tenant has not permitted, and closing a permitted route ends the sessions it issued at once - both proved end to end in `apps/service/src/google-sign-in.test.ts` and `sign-in.test.ts`                                                                                                                                                                                                                                                                |
| **IAM-054** | `admitGoogleAccount` (`apps/service/src/google.ts`) admits only an invited address or a named Workspace domain and refuses any other authenticated Google account, proved by `google.test.ts` and the `google-sign-in.test.ts` case that signs in as an uninvited address and is refused                                                                                                                                                                                                  |
| **STY-027** | `resolveStyle` (`packages/domain/src/theme/resolve.ts`) throws a named `ThemeError` for a style identifier the theme lacks rather than substituting one, proved by `resolve.test.ts` - the mechanism a publish step fails on rather than silently defaulting                                                                                                                                                                                                                              |
| **STY-038** | `resolveTheme` (`packages/domain/src/theme/resolve.ts`) is a pure function of the one value it is given: `resolve.test.ts` calls it twice on identical input and asserts identical output, with the input itself left unmodified                                                                                                                                                                                                                                                          |
| **STY-050** | The space between two blocks is the first's space-after plus the second's space-before, in every projection - CSS achieves this with padding plus a negative bottom margin that cancels the half-leading correction (`css.ts`), which is why `css.test.ts:20` asserts `padding-top: 12.912pt`, not a bare `12pt`, for a style whose resolved space-before is 12; Typst's data (`typst.ts`) and Word's `w:spacing` (`ooxml.ts`) pass the two values unchanged, each proved by its own test |
| **STY-051** | Line spacing carries the same literal points value into CSS's `line-height`, Typst's `lineSpacing` field and Word's `w:line` with `w:lineRule="atLeast"` - a stated minimum, never a multiple - each proved by its own projection's test                                                                                                                                                                                                                                                  |
| **DAT-027** | `takeValue` and `formatValue` (`packages/domain/src/data/`) take the one value the document holds and format it by the theme's value catalogue; the document page draws it where the binding stands, in the read text and the editor opened in place, proved by `DocumentPage.test.tsx`'s DAT-027 test                                                                                                                                                                                    |
| **DAT-031** | `takeValue` (`packages/domain/src/data/take.ts`) answers `value_many` with the count for a take of one column from more than one row and never takes the first, proved by `take.test.ts`                                                                                                                                                                                                                                                                                                  |
| **DAT-032** | `takeValue` answers `value_none`, `value_null` or `value_empty` for no row, a null or text of no characters or spaces alone, and never an empty string, proved by `take.test.ts`                                                                                                                                                                                                                                                                                                          |
| **DAT-041** | A value in a document's read text is a button that opens `ProvenancePanel` by a click or Enter, in one step, proved by `DocumentPage.test.tsx`'s DAT-041 test                                                                                                                                                                                                                                                                                                                             |
| **DAT-047** | A binding with no value shows why in place, set apart by its words and border, and the rest of the component draws as before - in the editor (`packages/editor/src/bindings.test.ts`) and in the document's text and its open editor (`DocumentPage.test.tsx`)                                                                                                                                                                                                                            |
| **DAT-022** | The query definitions listing answers each definition's connection `identity` to a reader of the definition who may not read its connection, proved by `apps/service/src/placing-bindings.test.ts`, and the Value dialog says **Runs as** beside each definition and on the one chosen, proved by `apps/web/src/editor/ValueDialog.test.tsx`; the browser suite's `tests/browser/src/placing.test.ts` shows it in Chromium                                                                |

## Excluded

| ID          | Reason                                                                                                                                                                                                                                                                                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IAM-018** | Named only by a `rule:` field, which establishes `Covered` but never `Verified`, and claimed by no design. It cannot be traced end to end, so this release does not claim it.                                                                                                                                                                               |
| **STY-009** | The theme's character catalogue (`packages/domain/src/theme/schema.ts`, `markNames`) renders only two of the eight marks CNT-031 requires - `strong` and `emphasis`. Underline, subscript, superscript, inline code, defined term and quoted phrase have no character style yet, so "each mark" is not met.                                                 |
| **STY-037** | The CSS projection omitting pagination-dependent properties (`css.test.ts`) is a prerequisite, not the requirement: the requirement is that the editor's preview shows the effect it cannot reproduce, and this repository has no editor or preview (`CLAUDE.md`: no authoring UI, no publishing).                                                          |
| **STY-052** | The typeface schema (`packages/domain/src/theme/schema.ts`) has an optional `wordFamily` but records no licence or embedding permission at all, for PDF or Word, and no publish report exists anywhere in the repository. The cited test proves only that a declared `wordFamily` is used, not the licence gate or the report the requirement also demands. |
