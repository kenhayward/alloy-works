# 0.13.0

> **Declared:** 2026-09-13. What this release is answerable for: the tenant-isolation and
> authentication-route rules in `service-foundations.md`, and the style-resolution and cross-format
> determinism rules in `themes.md`.

## Included

| ID          | Why it is in force                                                                                                                                                                                                   |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IAM-004** | Every route runs through a shared harness that signs in to one tenant and calls it again with another tenant's hostname and identifiers, and the response is refused                                                 |
| **IAM-043** | Sign-in reads a tenant's own record of which routes it permits before offering a provider, and closing a route ends the sessions that route issued                                                                   |
| **IAM-054** | A Google sign-in checks the authenticated address against the tenant's invited addresses and named Workspace domains before a session is issued, rather than admitting any authenticated Google account              |
| **STY-009** | The theme's character catalogue carries an explicit rendering for every mark in the node-and-mark model, so no mark renders by an implicit default                                                                   |
| **STY-027** | The resolver treats a style identifier the theme does not contain as a named resolution error, and a resolution error fails the publish rather than falling back to a default                                        |
| **STY-037** | Properties that depend on pagination are marked as such in the property set, so the editor's live view omits rather than approximates them, and preview is what actually shows the paginated effect                  |
| **STY-038** | The one resolver in `packages/domain` is a pure function of theme version, catalogue version and asset dimensions, with no other input that could make the same three produce two different appearances              |
| **STY-050** | Block spacing is computed once, as the first block's space after plus the second block's space before, and every output projection renders that same value rather than reinterpreting the two numbers                |
| **STY-051** | Line spacing is stored as one baseline-to-baseline distance in points, and every projection renders that literal distance rather than translating it through a format-specific multiple                              |
| **STY-052** | Every typeface artifact records whether its licence permits embedding, separately for PDF and Word, and the Word projection substitutes the declared permitted face and names the substitution in the publish report |

## Excluded

| ID          | Reason                                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IAM-018** | Named only by a `rule:` field, which establishes `Covered` but never `Verified`, and claimed by no design. It cannot be traced end to end, so this release does not claim it. |
