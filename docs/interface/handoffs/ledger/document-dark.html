4.1 Torque values for the pump housing v0.7, Reference Editing

Tighten the housing bolts in the order shown in Figure 2.1, in two passes. A seating pass at half the final value prevents the gasket from creeping.

  1. Fit the gasket dry. Do not use sealant on the mating face.
  2. Run every bolt down to 40 Nm in the sequence shown.
  3. Repeat the sequence at 85 Nm, then check each bolt once more.
4.2 Electrical ratings v1.2, Reference

The model 400 draws 4.2 A at 230 V, single phase. Where site supply falls below 207 V the pump derates; see Table 4.1.
