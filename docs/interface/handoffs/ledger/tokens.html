Ledger tokens

A replacement for tokens.css. One block per theme under data-theme on html, Auto maps prefers-color-scheme onto them. The header follows the theme; --doc-* stays as it is, so a page is always paper.

Rules

  • One accent. Status colours only ever mean status.
  • Warn is not approved, changes not in a version, checks failing. Info is someone else editing, or a newer version.
  • IBM Plex Sans for the interface, Plex Mono for numbers, versions and identifiers.
  • Panels are named in words. No two-letter codes.
  • colours.test.ts keeps both blocks naming the same tokens.
