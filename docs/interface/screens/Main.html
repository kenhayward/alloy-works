Routes

Hash routes, kept as the code has them so the desktop shell can load over file://. Every screen is addressable; every outline node too.

Route Screen Layout
#/ Home Module cards
#/components Components A
#/components/{id} Component editor B
#/components/{id}/access Access to a component B, dock open
#/documents Documents A
#/documents/{id} Document, outline and text C
#/documents/{id}/{node} The same, at that part C
#/publications Publications A
#/publications/{id} A publication D
#/search?q= Search results A
#/sign-in Sign in Frosted panel

Administration, New component, New document, Give access and Remove are modals over the screen that asked for them, never routes of their own.

Modules

Components
Author and version the typed pieces. The editor lives here.
Documents
Assemble outlines from components, number them, publish them.
Publications
Read what was published. Never edited, never changed.

Administration is not a module. It is a modal from the account chip, as Tenant Administration is in the source system: spaces, roles, people and invitations, component types, layouts.

Tokens, by surface

bg The page behind every module
surface Cards, tables, editor body, modals
surface-2 Filter pane, space pane, facet dock
accent Primary button, links, selection, section numbers
accent-weak Row hover, selected row, active tab
header-bg The header band, dark in both themes
warn Unsaved dot, not approved, refused publish
concept-bg Cross-references and defined terms in text
doc-page A publication, on doc-canvas

Write var(--token), never a hex. Light, Dark and Auto set data-theme on the html element; the header band stays dark in both.

Rules these screens follow

  • One action colour. Nothing else is a button fill.
  • Hairlines, not shadow. Shadow only on what floats.
  • Sentence case everywhere; module names Title Case.
  • Plain hyphens, straight quotes, ASCII only.
  • Every control is a real button, a, input or label.
  • Icon-only buttons carry a title and an aria-label.
  • Version numbers and counters use tabular-nums.
  • Nothing animates but a 120ms card lift and spinners.
