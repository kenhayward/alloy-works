### Added

- **Bound tables, stored and resolved.** A component can hold a table bound to a whole query result, with its columns, headers, units, formats and sort, placed through the API; its binding is resolved, checked, accepted and kept like any other, and the Data tab shows it holding. Publishing one is refused by name until the next release step lays it out.
- **Table formats in the default theme.** Table styles say how numbers, currencies, percentages, dates and durations print in a bound table, and the default layout gives the words for an empty table, a missing value and a source note.
