### Added

- **A floating toolbar on a table.** While you edit a plain table, a toolbar stands above it with rows, columns, merge and split, each saying why where it is unavailable. The table's name on it opens its settings without moving the right-hand panel. `F6` reaches it and `Esc` goes back to the cell.
- **The Table tab is a map of the table.** It shows the table's details and a grid of its cells: choose a cell, or use the arrow keys, to move there, and Shift to select cells. Beneath it are the row and column you are in, merge and split, and every setting.

### Changed

- **The Table tab no longer opens itself** when the cursor enters a table, plain or bound, so working through Threads is not interrupted. A dot on the tab says the cursor is in a table.
- **The Selection tab leaves Threads open** when the cursor enters a list or a figure.
- **Table settings changed form.** Header counts have - and + beside the number, Wide is three choices, and Numbered and the note beneath the table are switches.
