### Changed

- **The Bound table panel is a band of tabs.** It keeps one height under the toolbar while the cursor is in the table, so the text no longer jumps. Its first line is the value, with its definition as a link, and the table's settings as toggles; Columns, Sort and Notes each have a counted tab. The table is outlined while you are in it, the column whose row you are in is highlighted, and the status bar says which.
- **The value of a binding in one line.** The Value panel is a single line, its acts as icons.
