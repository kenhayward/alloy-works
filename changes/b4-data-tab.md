### Added

- **The Data tab.** Beside Contents in a document holding values: every value with its state, filtered by state, checked once on opening and by **Check now**, with **Accept**, **Resolve**, **Keep** and **Go to**.
- **A definition moved on is flagged.** A value floating on a definition that has a newer version says so, and a check of it waits to be accepted even where its rows are the same.
- **Changed since published.** Each value says how it differs from the document's latest publication.

### Fixed

- A value pinned to a definition version was offered, and could accept, a result of another version of that definition (#396).
