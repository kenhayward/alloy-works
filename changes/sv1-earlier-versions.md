### Added

- **Earlier versions in search.** Choose Versions: All on the Search page to find words in any earlier version of a component or a document; each result opens that version's own page, read only, at the place it matched.
- **Search a baseline.** Search this baseline, on a baseline's page, finds words only in what the baseline pins.
- **An earlier version's page.** Open, on each row of a Versions panel, shows that version read only.
